Sasana Gym · Assets CDN

Dokumentasi Aset Statis

Kumpulan library pihak ketiga, tema, dan gambar untuk aplikasi sasana-apps (CodeIgniter 4) — sistem manajemen membership, check-in, dan penjualan gym.

SasanaGym/assets branch: main 32 vendors · 286 berkas tema · 90 gambar

01 Pilihan CDN

Tiga jalur delivery aset. Pilih berdasarkan kebutuhan Content Security Policy (CSP) dan environment yang dipakai.

jsDelivr

CSP didukung Direkomendasikan

Global CDN dengan banyak mirror dan auto-fallback antar-mirror. Cache optimal karena versi dibaca dari git tag, plus dukungan Subresource Integrity (SRI) dan CORS header yang tepat. 

https://cdn.jsdelivr.net/gh/SasanaGym/assets@<versi>/vendors/jquery/jquery.min.js

Use case: production dengan kebijakan keamanan ketat.

GitHub Pages

Tanpa CSP

Tidak ada nonce/hash dan CORS terbatas, sehingga akan diblokir oleh kebijakan CSP yang ketat. Deployment otomatis lewat .github/workflows/static.yml (push ke main → seluruh isi repo diunggah sebagai artefak Pages). 

https://sasanagym.github.io/assets/vendors/jquery/jquery.min.js

Use case: development lokal, testing, dan prototyping tanpa requirement CSP.

StaticDelivr

CSP didukung

Domain konsisten sehingga mudah di-whitelist, dan otomatis fallback ke server asal bila CDN gagal atau terblokir. 

https://cdn.staticdelivr.com/gh/SasanaGym/assets/<versi>/vendors/jquery/jquery.min.js

Use case: alternatif production dengan kemampuan fallback.

Konfigurasi CSP

Whitelist domain jsDelivr agar aset bisa dimuat saat CSP aktif.

# Apache (.htaccess)
Header set Content-Security-Policy "script-src 'self' https://cdn.jsdelivr.net; style-src 'self' https://cdn.jsdelivr.net; font-src 'self' https://cdn.jsdelivr.net; img-src 'self' data: https://cdn.jsdelivr.net;"

# Nginx
add_header Content-Security-Policy "script-src 'self' https://cdn.jsdelivr.net; style-src 'self' https://cdn.jsdelivr.net; font-src 'self' https://cdn.jsdelivr.net; img-src 'self' data: https://cdn.jsdelivr.net;" always;

04 Cara Penggunaan

Contoh pemuatan aset, fallback chain, dan integrasi dengan aplikasi.

Cara 1 — jsDelivr (production)

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/SasanaGym/assets@<versi>/vendors/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/SasanaGym/assets@<versi>/themes/plus-admin/assets/css/style.css">

<script src="https://cdn.jsdelivr.net/gh/SasanaGym/assets@<versi>/vendors/jquery/jquery.min.js"></script>
<script src="https://cdn.jsdelivr.net/gh/SasanaGym/assets@<versi>/vendors/bootstrap/js/bootstrap.bundle.min.js"></script>

Cara 2 — Fallback chain

<script src="https://cdn.jsdelivr.net/gh/SasanaGym/assets@<versi>/vendors/jquery/jquery.min.js"></script>
<script>
    if (typeof jQuery === 'undefined') {
        document.write('<script src="https://sasanagym.github.io/assets/vendors/jquery/jquery.min.js"><\/script>');
    }
</script>

Cara 3 — Integrasi dengan sasana-apps

Aplikasi meresolusi aset lewat helper asset_url() (app/Helpers/asset_helper.php): kalau berkas ada di public/ pakai lokal, kalau tidak baru jatuh ke CDN. Penanda versi memakai filemtime() (?v=...), bukan ?r=time(). Base URL diambil dari App::$cloudUrl. 

<?php // app/Views/themes/modern/header.php ?>
<script src="<?= asset_url('vendors/jquery/jquery.min.js') ?>"></script>

Agar repo ini benar-benar terpakai, arahkan $cloudUrl ke sini: 

// app/Config/App.php
public const CLOUD_VER = '0.0.1';
public string $cloudUrl = 'https://cdn.jsdelivr.net/gh/SasanaGym/assets@' . self::CLOUD_VER . '/';

05 Versioning & Sinkronisasi

Semantic versioning MAJOR.MINOR.PATCH. jsDelivr & StaticDelivr membaca versi dari git tag, bukan dari nama branch.

🏷️

Saat ini repo belum punya tag. Buat tag pertama sebelum memakai URL ber-versi: 

git tag -a 0.0.1 -m "Rilis awal aset Sasana Gym"
git push origin 0.0.1
<!-- versi spesifik (disarankan untuk production) -->
https://cdn.jsdelivr.net/gh/SasanaGym/assets@0.0.1/vendors/jquery/jquery.min.js

<!-- major version -->
https://cdn.jsdelivr.net/gh/SasanaGym/assets@0/vendors/jquery/jquery.min.js

<!-- latest -->
https://cdn.jsdelivr.net/gh/SasanaGym/assets@latest/vendors/jquery/jquery.min.js

Aturan sinkronisasi

  1. Ubah dulu di sasana-apps/public/, lalu salin ke sini — bukan sebaliknya. Kalau tidak, versi lokal dan CDN bisa berbeda dan bug-nya sulit dilacak.
  2. Jangan mengubah berkas hanya di repo ini; perubahan akan tertimpa pada sync berikutnya.
  3. Naikkan tag versi setelah perubahan yang memengaruhi aplikasi, lalu update CLOUD_VER di sasana-apps/app/Config/App.php.
rsync -a --delete /d/DEV/PHP/sasana-apps/public/vendors/ vendors/
rsync -a --delete /d/DEV/PHP/sasana-apps/public/themes/  themes/
rsync -a --delete /d/DEV/PHP/sasana-apps/public/images/  images/

06 Catatan Penting

⚠️

app/Config/App.php di sasana-apps masih menunjuk repo lama: https://cdn.jsdelivr.net/gh/vizitripdotcom/assets@0.1.42/. Selama belum diubah, aset dari repo ini tidak akan pernah dimuat.

  • Repo ini adalah cermin dari sasana-apps/public/ — bukan sumber kebenaran.
  • GitHub Pages perlu diaktifkan di Settings → Pages (branch main, root) agar URL sasanagym.github.io aktif.
  • Selalu uji kompatibilitas CSP di staging sebelum deploy ke production.
  • Perubahan pada themes/ harus sejalan dengan folder public/ di repository sasana-apps.
  • Library pihak ketiga di vendors/ dan themes/*/assets/vendors/ tunduk pada lisensi masing-masing.
